# Endpoint Hardening
	
	Reducing its attack surface to the minimum the job requires, workstations and servers alike. Measured results against ==Baseline Configuration== to combat Drift.
	
	Baseline covers Interfaces, services, Ports, and Storage
	
Endpoint Protection
	
	5 Foundational Controls
	
	
		Segementation - Dividing network so endpoints can only reach what they need
		
		Isolation - Cut device off entirely
		
		Antivirus/AntiMalware - Signature & behavior based dectection of malicious code 
		
		Disk Encryption - protects data at rest
		
		Patch Management - The Process, NOT the act
	

	==Advanced Endpoint Protection==
	
		EDR - Endpoint Detection & Response
			Continuous Record of Endpoint Activity
		
		XDR - Extended Detection & Response
			Correlates endpoint telemtry w/ Network, email, & identity data to see attack across whole network.
		
		HIDS/HIPS - Host Based Intrusion Detection/Prevention
			Refer to previous notes (link will be placed here)
		
		UBA/UEBA - User & Entity Behavior Analytics
			Models what each user & device normally does, flags an account behaving unlike itself.

# Mobile Device Hardening

	==**Techniques**==
	
		BYOD - bring your own device
		
		COBO - corporate owned, business only
		
		COPE - Corporate owned, personally enabled
		
		CYOD - choose your own device, from an approved list
	
	
	==**Full Device Encryption**==
	
		Mobile devices handles data on SSD making it difficult to fully access if full encryption is in place.
		
		How is it alternatively handled?
		
			User data encrypted
			Data Protection using apps/email data are subject to second round of encryption
			Data Protection encryption is automatically enabled when Password lock is configured
		
		
	==**Location Services**==
	
		GPS
		IPS - Indoor Positioning System. Using Wi-fi, blutooth, cellualr to locate device while inside a building
		Geofencning - Defines virtual boundary and triggers action on device entry or exit
		GPS tagging - Embeds location into a file

	**==Misc==**
		
		Tethering is Security Risk Potentially
			Phone acting as hotspot creates unauthorized bridge between cellular network and whatever connect to it. Traffic circumvents all network controls and bridge runs both ways.
		
		Rogue & Evil Twin Networks
			Attacker's access point imperspnating trusted one

# Compact Summary: Advanced Cloud Architecture (Security+ Prep)

This document summarizes modern cloud architecture principles, focusing on automation, modularity, and scalability.

### ☁️ Deployment Models

- **VMs:** A multi-layered model (includes full OS).
- **Containers:** Lighter than VMs; built upon the host OS and Docker engine.
- **Serverless:** Pay-per-use. The provider manages infrastructure; developers only write functions/microservices (e.g., AWS Lambda).

### 🧩 Application Architectures

- **Microservices:** Breaking a large application into many small, independent services, each responsible for a single business capability.
    - _Benefit:_ Faster development and component-level scaling.
    - _Risk:_ Integration complexity across the entire system.

### 🚀 Transformational Cloud Services

Key services that change traditional development:

- **Auto-scaling & Elasticity:** Dynamically adjusting compute resources based on real-time demand.
- **CDN (Content Delivery Network):** Caching content geographically closer to the user to optimize web traffic.
- **Object Storage:** Massive, unstructured data storage solution.
- **IAM (Identity and Access Management):** Advanced security and permission management.

### ⚙️ Automation & Infrastructure

- **Infrastructure as Code (IaC):** Defining infrastructure using machine-readable definition files (YAML, JSON, HCL). Enables _consistent_ and repeatable provisioning across all environments (Dev, Staging, Prod), minimizing manual errors.

### 🌐 Advanced Networking

- **SDN (Software Defined Networking):** Separates the network's control functions from its physical forwarding hardware.
    - **Planes:**
        1. _Management:_ Monitors overall traffic conditions.
        2. _Control:_ Makes decisions on routing and prioritization.
        3. _Data:_ Handles the actual packet switching/routing.
    - _Functionality:_ Policies are defined in the control plane and enforced via APIs (Northbound/Southbound).

### ⚡ Performance Mechanisms

- **Load Balancing:** Distributes incoming network traffic to ensure high availability.
- **Edge Computing:** Processing data closer to the source ("the edge") to minimize latency, crucial for IoT.
- **Auto-Scaling:** Automatically provisions or de-provisions resources based on actual demand, optimizing cost and performance.

# Application Vulnerabilities

Race Condition
	Two Operations depend on timing and the outcome changes if their order changes

TIme of Check to TIme of Use (TOCTOU)
	System checks a condition, then acts on it -- and something changes in the gap between the two

Memory Injection
	An attacker writes their owne code or data into the memory space of a running process

Buffer Overflow
	More data is written than the allocated meory can hold, overwriting adjacent memory -- including the return address

Type-Safe Languages
	Prevents many memory errors at compile time

	Set of standards that let security tools exchange this data automatically.

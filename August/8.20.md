# 

**Malware Classification

*Vector vs Payload (Means vs Objective)

Viruses - Needs something to ride inside
	Non-resident/file injector (Attached to executable file)
	Memory Resident (loads into memory and infects files as they're opened)
	Boot  (Infects the boot sector)
	Script/macro (hides inside a docs' scripting language)

Worms - No host file required
	Can exploit remote execution and memory residence
	Persistence via the registry

Trojans
	Backdoor Malware: any mech giving an attacker access bypassing normal authentication
	RAT (Remote Access Trojan) - trojan whose payload is a backdoor
	Bot & Botnets: Malware that turns host into a bot
	Command & Control (C2/C&C): The infrastructure the attacker uses to issue instructions to bots
	

PUPs (Pre-installed bloatware)

*Spyware, Adware, & Keyloggers

Adware - PUP or bloatware, changes browser settings
Spyware - Genuine malware, logging all local activity
Keylogger - Records every keystroke

*Rootkits* (==VERY SEVERE==) IMMEDIATE REIMAGING
	Compromising System at the trustworthy level
	Replaces key system files & utilities
	Purge Log files
	Firmware rootkits

*Ransomware, Crypto-Malware, Logic Bombs*

Ransomware - locks user out by replacing shell, underlying data often untouched

Crypto-malware (high impact) encrypts data files or entire drives

Cryptomining/jacking - hijacks victims compute resources to mine crypto for attacker

Logic Bombs - malicious code that lies dormant until specific condition is met

TTPs - Tactics, Techniques and Procedures
	Pattern of threat actors

IoCs - Indicators of Compromise
	Specific observable evidence that a compromise has actually occurred

# Physical & Network Attack Indicators


**Physical Attacks

Brute Force
Environmental - attacking power, cooling or fire suppression. Environmental denial of service
RFID Cloning & Skimming 


**Network Attack Stages

*6 stages*

Recon & Credential Harvesting
Denial of Service
Weaponization/delivery/breach
Command & Control, Beaconing, Persistence
Lateral Movement, Pivoting, Privilege Escalation
Data Exfiltration


**Distributed Denial of Service Attacks

Overwhelming Target w/ Borrowed Bandwidth
	Uses Botnet/Zombies
	Coordinated by C&C network

*Named Variants*
Reflected: Spoof Victim's IP and open connections
Amplified: Bogus DNS or NTP queries direct responses at the victim, generate very large response packets


**On-Path Attacks (Man-in-the-middle)

Threat Actor positioned between two hosts
Focused on snooping traffic that was never intended for them

Uses ==ARP Poisoning== (broadcast ARP replies to poison cache of local hosts w/ a spoofed MAC address)

DNS Attacks

# Application Attack Indicators

**Application Attacks

Vertical Privilege Escalation  - User to Root or Admin access
Horizontal Privilege Escalation - Moving Sideways

**Reply Attacks

Reusing token instead of forging one
Resubmits or guesses authorization tokens

**Cross Site Request Forgery

Client Side Forgery - Passes URL to another site where victim already has authenticated session

Server Side - Cause a server to make API calls or HTTP requests w/ arbitrary parameters. Attacker never touches internal target directly

**Directory Traversal & Command Injection (No Clipping)

Obtaining access to files outside website's root dir - walking up folder tree with "../" until escaping boundary entierly

Command Injection - Causes server to run OS shell commands directly (==EXTREME SEVERITY)

# Using Fields in Searches

*What are Fields?*

Fields are searchable key-value pairs within event data.

Fields make searches more precise and efficient
	- Example: status=200, host=webserver1, user=jdoe

*Types*

- Indexed Fields: Extracted when data is indexed
- Search-Time Fields: Extracted dynamically when running a search
Indexed improve search speed, search-time provide flex

*Using Fields Sidebar*

Appears in Search&Reporting Tab

*Extracting & Selecting Fields*

Default Selected Fields: hots, source, sourcetype.

Users can add fields from Interesting to Selected for better control.


*Searching w/ Fields For Efficiency*

Field-based searches provide relevant results rather than keyword based

*Wildcards*

Matches multiple characters in a search

Best practices:
	Use wildcards at the end
	Avoid using at the beginning

*Saving & Exporting Search Results*

Save searches as:

- Reports
- Alerts
- Dashboards

Export Options: CSV, JSON, XML, Raw Events

*Booleans Operators*

Combining AND, OR, NOT statements


Difference Between != and NOT

!= (Not Equal To): Excludes specific values

NOT Operator: excludes all events containing specified value, even if the field is missing.000

*Renaming Fields*
==rename== command makes field names more user-friendly

*Best Practices*

- Always use specific fields
- Use Booleans and wildcards wisely
- Format results with table for better readability
- Use rename correctly

# Splunk Basics

**Splunk** 
	Platform for searching, analyzing & visualizing machine-generated data. Aggregator 
	*Use Cases* - IT Ops, Business Analytics, IoT, Security


**Core Functions**

- Index Data
	- Organizes machine data

- Search & Investigate
	- Queries & filters data

- Add Knowledge
	- Custom fields, tags, data enrichment

- Monitor & Alert
	- Real-time monitoring & alerts for specific events

- Report & Analyze
	- Data Visualization 


**Splunk Components**

Forwarders
	Collects & sends data to indexers. Sits on source machines

Indexers
	Stores & processes data for searching

Search Heads
	Enable users to run searches & visualize data

**Splunk APps & Add-ons**

Apps
	Pre-built packages w/ dashboards, reports & specific functionality

Add-ons
	Provide additional data inputs

# Intro to Splunk Searching

*Adding Data to Splunk*

Splunk ingest logs, metrics & event data from multiple sources

*Methods*:

Splunk Web Interface
Command-line Interface
Automated Data Inputs (forwarders, logs, databases)

Data is indexed & assigned a sourcetype for easy retrieval

*Understanding Indexing & SourceTypes*

Indexing stores & organizes ingested data
Sourcetypes defines the format & structure of data


**Running Basic Searches in Splunk**

Searchess can be based on:

Keywords
Key-Value Pairs - Example: status=200
Wildcards * - Matches multiple values

*Refining Searches w/ Search Operators*

- AND
- OR
- NOT
- Default Operator: Implicit AND statement if no operator is used

*Time Modifiers & Search Optimization*

- Time Range Picker: Restricts searches to specific timeframe
- Absolute Time 
- Relative Time
- Snap to Time: earliest =-h@h (snaps to nearest hour)

# Search Language Fundamentals


*Dedup command*
Deduplication command, removes duplicates values

*sort command*
Puts Data in order
	Sort (ascending)
	Sort - (descending)

**eval command**
Creates/change new/existing fields
	calculates new values dynamically
	EX: eval new_price = price x 1.2

*can be conditional*

IF:
	| eval status_text = if(status=200, "OK", "Error")

CASE:
	| eval error_msg
